### Запуск проекта

1) Скопировать `.env-example` в `.env` и при необходимости изменить локальные значения
2) Запустить локально `mysql` или `mariadb` (можно использовать `docker/mysql.yml`)
3) Настроить переменные окружения в файле `.env`
4) Выполнить миграцию `database/mysql/users.sql`
5) Установить библиотеки `npm i`
6) Запустить проект `npm start`, интеграционные тесты: `npm test`

### Локальная arena shooter игра

В проект добавлен легальный Quake-like прототип без оригинальных ассетов Quake III.
Карта сделана по канонам deathmatch-арен Q3: симметрия, gothic/tech материалы,
центральный pit с jump pad, боковые комнаты и классическая раскладка предметов.

1) Установить зависимости: `npm i`
2) Запустить сервер: `PORT=3000 npm start`
3) Открыть в браузере: `http://localhost:3000/game`

Управление:

- `WASD` — движение и стрейф
- `Mouse` — обзор
- `ЛКМ` — выстрел
- `Space` — прыжок, при стрейфе в воздухе сохраняет скорость
- `Shift` — ускорение
- `R` — сброс матча
- На смартфоне: левый виртуальный стик — движение, свайп справа — обзор, удержание `Fire` — стрельба, `Weap` — смена оружия, `Jump`, `Run`, `Reset`
- Оружия Q3-style: Machine Gun (старт), Shotgun, Rocket Launcher, Lightning Gun, Railgun, Plasma Gun
- Клавиши `1-6` / `Q` `E` — смена оружия; на карте подбирайте `S/O/E/U/P`
- Rocket jump: выстрел рядом с собой отталкивает игрока вверх и в сторону от взрыва
